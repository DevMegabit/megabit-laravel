# megabit-laravel

Driver Firebird para o **Laravel 12 e 13**, com **migrations no Firebird 3, 4
e 5**. Mantido pela Megabit.

> **Versões**
> - **2.x** (este branch): Laravel 12/13, PHP 8.2+. Firebird 3, 4 e 5.
> - **`master` (1.x)**: Laravel 5.5 a 8, PHP 7.2 (o código do Simonov). É o
>   que o Catálogo e o gestaoweb usam hoje. **Não misturar:** a 2.x não roda
>   no Laravel 8, e a 1.x não roda no 12/13.

## Instalação

O pacote não está no Packagist. No `composer.json` do projeto:

```json
"repositories": [
    { "type": "vcs", "url": "https://github.com/DevMegabit/megabit-laravel" }
],
"require": {
    "devmegabit/megabit-laravel": "2.x-dev"
}
```

O provider (`Firebird\FirebirdServiceProvider`) é registrado sozinho. A
extensão `pdo_firebird` e a biblioteca de cliente do Firebird precisam estar
no PHP.

## Conexão

No `config/database.php`:

```php
'firebird' => [
    'driver'   => 'firebird',
    'host'     => env('DB_HOST', 'localhost'),
    'port'     => env('DB_PORT', '3050'),
    'database' => env('DB_DATABASE', '/caminho/do/banco.fdb'),
    'username' => env('DB_USERNAME', 'SYSDBA'),
    'password' => env('DB_PASSWORD'),
    'charset'  => env('DB_CHARSET', 'UTF8'),
    'role'     => null,
],
```

## Migrations

Funcionam no Firebird 3, 4 e 5 (testado em todos):

- `increments()`/`id()` viram `GENERATED BY DEFAULT AS IDENTITY`, o que
  inclui a tabela `migrations` do próprio Laravel;
- chave primária com nome (`$table->primary([...], 'NOME')`), índices,
  `unique`, chave estrangeira;
- `Schema::table()` para acrescentar coluna; `dropColumn()`, `dropIndex()`;
- `Schema::hasTable()`, `hasColumn()`, `getColumnListing()`, `getIndexes()`,
  `hasIndex()`.

Os nomes de índice e de constraint são cortados em **31 caracteres**, o
limite do Firebird 3.

**O que não faz:** criar o banco (o `pdo_firebird` só conecta num banco que
existe; use o `isql`), tabela temporária, `change()` de coluna, `renameColumn()`.

## Testes

A suíte usa um Firebird de verdade (`orchestra/testbench`). Com Docker:

```bash
docker compose up -d firebird-v3   # ou firebird-v4, firebird-v5
DB_HOST=localhost DB_PORT=3053 DB_PASSWORD=masterkey vendor/bin/phpunit
```

O CI (`.github/workflows/tests.yml`) roda PHP 8.3/8.4 × Laravel 12/13 ×
Firebird 3/4/5.

## O que a Megabit mudou sobre o código de origem

A base é o `harrygulliford/laravel-firebird` 4.0.0-beta.1 (MIT). Mudanças,
marcadas com "Megabit" no código:

- namespace `Firebird\` (o mesmo da 1.x), no lugar de `HarryGulliford\Firebird\`;
- `modifyIncrement` (IDENTITY), `compilePrimary` com nome, `compileDropColumn`,
  `compileDropIndex`, `compileIndexes` e `processIndexes`: sem eles, as
  migrations não rodavam (a tabela `migrations` falhava com o `id` nulo);
- testes: a fixture usa `GENERATED BY DEFAULT` (o `ALWAYS` só existe a
  partir do Firebird 4), mais `MigrationTest` e `SchemaGrammarTest`; o CI
  inclui o Firebird 3.
